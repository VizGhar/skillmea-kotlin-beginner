# 7.5 Enumy

Zoznamy povolených hodnôt sú ideálnou pomôckou tak pre programátora
ako aj pre kompilátor. Tým že presne vieme aké hodnoty môže nadobúdať
premenná, nepomýlime sa v nastavení hodnoty premennej, a kompilátor
vie napríklad zistiť, kedy už sú vymenované všetky možnosti napríklad
vo whene.

## 7.5.1 Directions

Uprav úlohu 
[7.3.2 Level - privátna funkcia](07-03-visibility_modifiers.MD)
tak, aby si namiesto čísel 0-3 posielal do funkcií `look` a `go` posielal
hodnoty enumu s názvom `Direction`, napríklad `Direction.TOP` alebo
`Direction.RIGHT`. Ak je to vhodné, pridaj tomuto enumu aj atribúty.

## 7.5.2 State

Uprav úlohu [5.2.2 Objednávka](../05-cleanup/05-02-exceptions.MD)
tak, aby stavy objednávky bol Enum. V tomto enume zároveň implementuj funkciu,
ktorá vráti zoznam stavov, do ktorých sa z aktuálneho stavu dá dostať.

Teda napríklad:
1. zavolanie `Status.Processed.allowedStates()` vráti `listOf(Status.Dispatched, Status.Cancelled)`
2. zavolanie `Status.Cancelled.allowedStates()` vráti `emptyList()`
3. ...

## 7.5.3 Menu > Settings > Languages

Ako predlohu uvažuj úlohu [5.5 Locale](../05-cleanup/05-05-locales.MD), resp.
[6.5.1 Locale](../06-collections/06-05-map.MD). Vypíš zoznam podporovaných jazykov
aplikácie. Tento zoznam musíš získať z enumu. Enum by mohol mať nasledovnú hlavičku:

```kt
enum class Translation(
    val languageName: String,
    val shortcut: Char,
    val translations: Map<String, String>
)
```

Kde
- `languageName` je názov, ako sa zobrazuje v menu (napr.: `[S]lovensky`)
- `shortcut` je skratka, ktorou tento jazyk zvolím (napr.: pre `[S]lovensky` je to `'S'`)
- `translations` je premenná so všetkými prekladmi pre daný jazyk
