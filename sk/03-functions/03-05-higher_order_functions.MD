# 3.5 Funkcie vyššieho rádu

## 3.5.1 Základ

Napíš funkciu `check`, ktorá:
1. prijíma 3 čísla a literál
2. vracia `Boolean`
3. pričom literál prijíma 2 čísla a vracia `Boolean`

Literál v tejto funkcii volaj nad dvojicami _A-B_, _A-C_ a _B-C_

Ak vo všetkých prípadoch literál vráti `true`, aj funkcia `check` vráti `true`

Napríklad pri vstupe `1 5 7` a literály `a < b` vráti naša funkcia `true`, pretože:
1. `1 < 5`
2. `1 < 7`
3. `5 < 7`

Vyskúšaj tieto možnosti pre literál:
1. A < B
2. A > B
3. A je deliteľné B
4. A + B je párne
5. A aj B končia tou istou číslicou
