## 7.2.1 Shapes

1. Create a class `Shape2D` that represents any shape in 2D space.
2. Create a class `Circle` that extends `Shape2D` and contains an attribute `r`.
3. Create a class `Rectangle` that extends `Shape2D` and contains attributes `a` and `b`.
4. Create a class `Square` that extends `Rectangle` and contains an attribute `a`.
5. Shape classes (`Circle`, `Rectangle`, `Square`) implement functions for `content`

On standard input, read the number `n` followed by `n` lines:
1. If a line starts with the text `Circle`, then the same line also includes the number `r`.
2. If a line starts with the text `Rectangle`, then the same line also includes numbers `a` and `b`.
3. If a line starts with the text `Square`, then the same line also includes the number `a`

Store all `n` shapes in one list. Then, read another text - `Circle`, `Rectangle`, or `Square`. And from this list print only the sum of contents of these shapes. That is, if I read the text `Circle`, I will print the sum of all circles' contents.
