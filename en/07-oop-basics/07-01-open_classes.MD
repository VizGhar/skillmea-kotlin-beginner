# 7.1 Open Classes

And now let's take a look at actual object-oriented programming

## 7.1.1 Exploration

Create a `Company` class that includes attributes `name`, `latitude`, and `longitude` in its constructor.
This class will represent any food ordering company.

Implement the `order` function in this class, which simply prints out the name of the company.

Expand this class into the `Cafe` and `Hotel` classes:
1. In the `Hotel` class, add a `stay` function
2. In the `Cafe` class, add an `opening_hours` attribute

Create instances of the `Company`, `Hotel`, and `Cafe` classes and determine what attributes and functions you have access to in these objects
