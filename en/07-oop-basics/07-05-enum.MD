# 7.5 Enumy

Enums of allowed values are a great help both for programmers and compilers. We precisely know what values a variable can take, we don't mistake the setting value for a variable, and the compiler can for example determine when all options have been exhausted, for instance in a whene.

## 7.5.3 Menu > Settings > Languages

As a reference, consider the task [5.5 Locale](../05-cleanup/05-05-locales.MD), resp. [6.5.1 Locale](../06-collections/06-05-map.MD). Write out a list of supported languages by the application. This list must be obtained from an enum. The enum could have the following header:

```kt
enum class Translation(
    val languageName: String,
    val shortcut: Char,
    val translations: Map<String, String>
)
```

Where:
- `languageName` is the name as it appears in the menu (e.g. `[S]lovak`)
- `shortcut` is the shortcut by which you choose this language (e.g. for `[S]lovak`, it's `'S'`)
- `translations` is a variable with all translations for that language
