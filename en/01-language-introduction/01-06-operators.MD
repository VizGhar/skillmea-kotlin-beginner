## 16.2 Timers

Let's create simple timers that start and stop when you press the ENTER key:

1. Write "To start timer press ENTER" to the standard output.
2. When you press the ENTER key, store the current time in the `start` variable using `System.currentTimeMillis()`.
3. Write "To stop timer press ENTER" to the standard output.
4. When you press the ENTER key, store the current time in the `end` variable using `System.currentTimeMillis()`.
5. Write the difference between the values in the `end` and `start` variables (result is in milliseconds) to the standard output.
