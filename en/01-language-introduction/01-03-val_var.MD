## 1.3.2 Measuring Time

1. Store the current time by calling `System.currentTimeMillis()` into a variable (`var`)
2. Print the value in this variable using `println`
3. Store the current time again into the same variable
4. Print the value in this variable using `println`

_Note:_ The time obtained with `System.currentTimeMillis()` returns the number of milliseconds that have elapsed since 1/1/1970.
