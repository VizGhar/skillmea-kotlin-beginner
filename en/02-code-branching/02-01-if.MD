## 2.1.1 If - Handbook for Students

Read an entire integer on standard input. If it does not fall within the interval of 1-5, print:
"Enter a score from 1 to 5"

## 2.1.2 If-Else - Handbook for Students 2

Read an entire integer on standard input.
1. If it does not fall within the interval of 1-5, print: "Enter a score from 1 to 5"
2. If it falls within the interval of 1-5, print: "Thank you for grading"

## 2.1.3 If-ElseIf-Else - ISBN-13

ISBN-13 is a modern numerical identification for books or periodicals and also their bar code. Read text and determine whether it refers to ISBN-13 or not.

ISBN-13 consists of 13 digits and starts with numbers 978 or 979 

1. Read text on standard input
2. If this text has an incorrect length, print: "Incorrect length"
3. If this text starts with the numbers 978, print: "Book"
4. If this text starts with the numbers 979, print: "Other publication"
5. Otherwise, print: "Invalid format"
