# 2.2 For a Range

Use the `for` keyword to execute a part of your code multiple times.
Inside the for loop, you'll have a different value from the range you set for this for loop each time it iterates.

## 2.2.1 Simple For

Read an integer `n` from standard input.
Print numbers from `1` to `n` on one line with commas:

```1, 2, 3, 4, ... , n```

## 2.2.2 Range Operations

Read integers `n` and `k` from standard input. Print all multiples of `k` that are less than `n`. Can you do it using the `step` keyword?

## 2.2.3 Small Multiplier, Preparation

Use three for loops:

On the first line, print the first `10` multiples of `3`
On the second line, print the first `10` multiples of `5`
On the third line, print the first `10` multiples of `6`
