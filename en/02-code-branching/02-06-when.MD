# 2.6 When

Now we can "evaluate" multiple conditions at once. Or directly assign multiple cases to the `when` block.

## 2.6.1 Merchant Evaluation

Write a program to obtain the merchant's evaluation.

1. Print to standard output: _"How would you rate your experience on scale 1-5?"_
2. Store an integer value in the variable `mood` from standard input
   1. If `mood` is `1` or `2`, print _"Thank you for your vote!"_
   2. If `mood` is `3`, `4`, or `5`, print: _"Hope we can do better next time!"_
   3. If `mood` is outside the range `1-5`, print _"Incorrect input!"_

## 2.6.2 Dice

Read a text composed only of numbers. Calculate how many dice are in this text, as if it were written by hand.
- `8` has 2 dice
- `0`, `6`, and `9` have one die
- `1`, `2`, `3`, `4`, `5`, and `7` do not contain any dice

For example, the number `0123456789` contains `5` dice.
