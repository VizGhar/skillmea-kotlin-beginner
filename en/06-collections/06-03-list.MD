## 6.3.1 Dummy User

This task is very practical, especially for testing purposes or when creating your own mock web servers. Simply put, it's about creating several random users with semi-consistent data.

Create 3 TXT files:
1. with a list of at least 20 first names
2. with a list of at least 20 last names
3. with a list of at least 5 domains (what is found after the @ symbol in an email address)

And then program the following:

1. Load the list of first names `firstNames`
2. Load the list of last names `lastNames`
3. Load the list of domains `domains`
4. Upon application start, display 10 randomly generated users by printing:
    1. A random first name from the `firstNames` list
    2. A random last name from the `lastNames` list
    3. An email composed of `firstName.lower() + "." + lastName.lower() + "@domain`, where `firstName` and `lastName` will be in lowercase
