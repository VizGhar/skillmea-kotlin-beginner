## 6.5.2 

A large number of children comes from school and marks arrivals and departures with chips.

1. Load the number `n` - the number of chips
2. Load `n` pairs of `chip`, `name`
3. Load the number `m` - the number of visits
4. Load `m` records with chips
   1. If a chip does not exist, print _"Non-existent chip"_
   2. If a chip exists and the student has not yet arrived at school, print _"Arrived "_ and the name of the student
   3. If a chip exists and the student has already arrived at school, print _"Departed "_ and the name of the student
