- 7♠,7♥,7♣,7♦,8♠,8♥,8♣,8♦,9♠,9♥,9♣,9♦,10♠,10♥,10♣,10♦,J♠,J♥,J♣,J♦,Q♠,Q♥,Q♣,Q♦,K♠,K♥,K♣,K♦,A♠,A♥,A♣,A♦

## 6.6.2 firstOrNull/lastOrNull

You can call the `firstOrNull` function over a `List`. This will return `null` if the list is empty. In the `main` function, read an integer `n` and then `n` lines of text.

Print the first and last item from this list to standard output.

Try to learn more about this function and try to print
the first item starting with the letter `A`
