## 6.4.2 Travel Journal

A traveler will no longer visit a city twice.

1. Read numbers `m` and `n`
2. Read the list of `n` cities where the traveler has already been
3. Read the list of `m` cities to which they are planning to travel

Display on standard output only the cities from the second list where the traveler has not yet been.
