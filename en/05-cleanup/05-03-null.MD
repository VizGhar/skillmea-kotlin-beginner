# 5.3 Null

Null = none

## 5.3.1 Simple
Write a function that takes a text as input. This function should return the sum of digits in this text, or `none` if no digit is found.

## 5.3.2 toIntOrNull
Read numbers from standard input and print them immediately.
If the read text is not a number, exit the program.
Do not use exceptions.
