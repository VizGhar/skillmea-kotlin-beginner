# 3.3 Default Attributes of Functions

Sometimes function parameters have values that don't change often. In astronomical calculations, you will usually work in metric units. The temporary file for operations will typically be called `temp` and so on.

# 3.3.1 VAT Calculation
Write a function to calculate VAT. The default value of VAT shall be 20%.

# 3.3.2 Text Repeater
Write your own `println` function that accepts text and the number of repetitions, in addition to the original text. The default text will be printed only once.

# 3.3.3 Circle Content
Write a function to calculate the content of a circle. If the second side is not specified, it will be treated as a square. (You can use the value of another attribute as the default)
