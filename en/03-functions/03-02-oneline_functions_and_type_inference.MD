# 3.2 Single-Parameter Functions and Type Inference

Single-parameter functions are usually computational functions. I'll give you a proposal for a few mathematical/physical functions. Find the formulas online:

1. BMI - function that takes weight (kg) and height (cm) and returns BMI value
2. Percent - function that takes decimal number. Returns integer representing % (0.51 = 51%)
3. Circle Circumference – function that takes radius r and returns circle circumference.
4. Circle Area – function that takes radius r and returns circle area.
5. Pythagorean Theorem – function that takes side lengths a and b, and returns hypotenuse length.
6. Uniform Motion – function that takes velocity v and time t, and returns traveled distance.
7. Uniformly Accelerated Motion – function that takes initial velocity v0, time t, and acceleration a, and returns distance.
8. VAT Calculation – function that takes price without VAT and VAT rate, and returns price with VAT.
9. Conversion °C to °F – function that takes temperature in Celsius degrees and returns it in Fahrenheit degrees.
10. Conversion °F to °C – function that takes temperature in Fahrenheit degrees and returns it in Celsius degrees.
11. Conversion km/h to m/s – function that takes velocity in km/h and returns it in m/s.
12. Conversion m/s to km/h – function that takes velocity in m/s and returns it in km/h.
13. Average Calculation – function that takes two numbers and returns their arithmetic average.
14. Geometric Mean Calculation – function that takes two numbers and returns their geometric mean.
15. Harmonic Mean Calculation – function that takes two numbers and returns their harmonic mean.
16. Discriminant Calculation for Quadratic Equation – function that takes coefficients a, b, c and returns the discriminant.
17. Cube Volume Calculation – function that takes length, width, and height and returns cube volume.
18. Cube Surface Area Calculation – function that takes length, width, and height and returns cube surface area.
19. Cylinder Volume Calculation – function that takes radius and height and returns cylinder volume.
20. Cylinder Surface Area Calculation – function that takes radius and height and returns cylinder surface area.
